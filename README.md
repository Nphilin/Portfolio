# 💻 José Pedro Luna — Portfolio

Bem-vindo ao repositório do meu portfólio pessoal. Este projeto foi desenvolvido com foco em um design minimalista, tipografia marcante e alta performance, utilizando tecnologias web puras (HTML, CSS e JavaScript) para criar uma experiência visual limpo e direta.

O objetivo deste espaço é apresentar a minha trajetória de transição de carreira para o desenvolvimento de software, unindo a minha bagagem em gestão e processos de negócios com o desenvolvimento Full-Stack.

---

## 🚀 Tecnologias Utilizadas

Para manter o projeto leve, responsivo e fiel à proposta estética inspirada em layouts editoriais modernos, utilizei:

- **HTML5:** Estruturação semântica para melhor acessibilidade e SEO.
- **CSS3:** Layout fluido com CSS Grid, Flexbox e variáveis nativas para fácil manutenção.
- **JavaScript (Vanilla):** Lógica pura para manipulação do DOM, efeitos suaves de scroll (Intersection Observer) e navegação interativa.

---

## 📁 Projetos em Destaque

No portfólio, destaco soluções práticas alinhadas com as stacks que venho a desenvolver na graduação:

1. **Mais Climatização (agendamentos-ui)**
   - *Descrição:* Interface moderna projetada para otimizar o fluxo de agendamento e gerenciamento de ordens de serviço para profissionais de refrigeração. Desenvolvida com foco em UX e total responsividade para dispositivos móveis.
   - *Techs:* HTML, CSS, JavaScript (e conceitos de componentização).

2. **Backend Architecture (Java / Spring Boot)**
   - *Descrição:* Construção de APIs e sistemas de gestão empresarial focados em regras de negócio robustas, aplicando Programação Orientada a Objetos (POO), classes abstratas e persistência.
   - *Techs:* Java, Spring Boot.
